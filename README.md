# Pato el Pez Web

Official website for Pato el Pez, showcasing the band's story, music, merchandise, and digital presence.

## Features

- Band presentation
- Music catalog
- Merchandise showcase
- Events section
- Contact information
- Responsive design

## Tech Stack

- React
- Vite
- CSS / Tailwind (optional)
- JSON data structure
- Future API integration ready

## Project Structure

src/
components/
pages/
data/
services/
routes/

## Installation

```bash
npm install
npm run dev
```
